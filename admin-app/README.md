# Admin Panel - ĐHSP TP.HCM

Hệ thống quản trị khảo sát sinh viên.

## Setup

```bash
npm install
cp .env.local.example .env.local
# Cập nhật .env.local với thông tin thực
npm run dev
```

## Deploy

```bash
npm run build
npm start
```
