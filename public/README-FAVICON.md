# Favicon Files

## ⚠️ Cần Cập nhật

Các file PNG và ICO hiện tại là placeholder. Cần thay thế bằng logo ĐHSP chính thức.

## 📝 Hướng dẫn

Xem file: `docs/FAVICON-GUIDE.md`

Hoặc nhanh:
1. Truy cập: https://realfavicongenerator.net/
2. Upload logo ĐHSP
3. Download package
4. Thay thế files trong thư mục này

## ✅ Files cần thay thế

- [ ] `favicon.ico` - Multi-size ICO
- [ ] `favicon-16x16.png` - 16x16 PNG
- [ ] `favicon-32x32.png` - 32x32 PNG
- [ ] `apple-touch-icon.png` - 180x180 PNG
- [ ] `android-chrome-192x192.png` - 192x192 PNG
- [ ] `android-chrome-512x512.png` - 512x512 PNG

## ✨ Đã có

- [x] `favicon.svg` - SVG version (modern browsers)
- [x] `site.webmanifest` - Web app manifest
